# A11Y

## QUÉ HACE

Acceso por teclado, sin scroll horizontal y contraste AA verificado.

## POR QUÉ SE IMPLEMENTÓ ASÍ

Axe corre en el flujo con criterios WCAG 2A y 2AA. Los colores de texto chico usan tonos que cumplen 4.5:1.

## CÓMO FUNCIONA

Enlace para saltar al contenido, foco visible, preguntas nativas operables por teclado y animación desactivable.

## REGLAS DE NEGOCIO

| Regla      | Detalle                                           |
| ---------- | ------------------------------------------------- |
| Teclado    | Todo operable, orden lógico, foco siempre visible |
| Movimiento | Sin animación con `prefers-reduced-motion`        |
| Capas      | Conteo en `docs/ui.md`, próximo nivel libre `4`   |

## SEGURIDAD ESPECÍFICA

Sin datos ni enlaces. Vale lo definido en [§5.1](../AGENTS.md#51-prohibido-sin-excepción).

## ARCHIVOS / SECCIONES / EVENTOS INVOLUCRADOS

| Ruta                        | Rol                                   |
| --------------------------- | ------------------------------------- |
| `index.html`                | Salto al contenido y punto de llegada |
| `src/styles/styles.css`     | Foco visible y salto                  |
| `e2e/accessibility.spec.ts` | Axe, responsive, teclado y salto      |

## TESTS

Flujos en Playwright, incluido Axe en estado estable.
